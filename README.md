# Teacher's Pet 🍎: installers

This repository holds only the Windows installers and update files for Teacher's Pet. It contains no source code.

**New to Teacher's Pet? Read the [one-page guide](USER_GUIDE.md):** installing, the first steps, and using it day to day.

**To install:** open the [latest release](https://github.com/AbdoZwein/teachers-pet-releases/releases/latest), download `teachers-pet-<version>-setup.exe` and run it. Windows may say it protected your PC: click **More info**, then **Run anyway**. That happens only once, because the installer is not code-signed.

Installed copies update themselves from here.
